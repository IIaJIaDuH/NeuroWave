# ADR-0002: Python-ядро как первый вертикальный срез

**Статус:** принято для Sprint 1, пересматривается при выборе UI-основы.
**Дата:** 2026-11-16.

## Контекст

ТЗ требует нативный Linux-клиент (Qt 6 / C++20) и одновременно —
работающее воспроизведение, авторизацию, очередь и кеш раньше, чем интерфейс
и ИИ. Sprint 0 (сравнение CloudMus/YaMusic) на целевой машине ещё не выполнен:
нет подтверждённых замеров, поведения Bluetooth/HDMI и решения по основе.
Писать сразу Qt-приложение значит зафиксировать UI и аудио-архитектуру до
проверки гипотез.

## Решение

Первый работающий срез реализован как **headless-ядро на Python**:

- адаптер Яндекс Музыки над неофициальной библиотекой `yandex-music`
  (Device Flow, поиск, волна, лайки, плейлисты, ссылки на поток);
- домен, очередь, машина состояний, сервис плеера;
- SQLite для истории, лайков и снимка очереди;
- ограниченный дисковый кеш (LRU, TTL);
- аудиовыход через `mpv` (JSON IPC) с интерфейсом `AudioBackend`;
- CLI для проверки всех сценариев без GUI.

Контракт `PlayerService`/`AudioBackend`/`MusicAdapter` — единственная точка,
к которой позже подключается Qt-интерфейс и DSP. Аудиопоток не зависит от
языка UI: это отдельный процесс `mpv`.

## Почему не C++/Qt сразу

1. **Скорость проверки гипотез.** Нужны ответы про OAuth, «Мою волну»,
   качество потоков и кеш, а не Qt-сборка.
2. **Риск API.** Неофициальный API меняется; изолировать его в адаптере
   дешевле, чем переписывать C++-клиент.
3. **Проверяемость.** Ядро покрывается unit-тестами без дисплея и звука.
4. **Обратимость.** Python-слой можно оставить сервисом (как у CloudMus) или
   заменить на C++-адаптер, не меняя модель данных и поведения.

## Последствия

- Появляется зависимость от Python 3.10+ и `mpv` в целевой системе.
- Qt UI и DSP должны общаться с ядром через явный контракт; это будет
  следующим ADR (выбор IPC/встраивания).
- Потребление памяти нужно измерить: Python-процесс добавляет к бюджету
  NFR-01; при провале бюджета ядро переносится в C++, тесты остаются как
  эталон поведения.
- Sprint 0 не отменяется: сравнение с CloudMus/YaMusic и замеры на Mint
  по-прежнему нужны до публичного релиза.
