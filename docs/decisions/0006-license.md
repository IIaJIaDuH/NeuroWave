# ADR-0006: лицензия проекта

**Статус:** **принято 2026-11-16** решением владельца проекта: MIT, замена
`mutagen` на `tinytag`, GPL-зависимость убрать из стандартной поставки.
Реализация — в этом же PR: `LICENSE`, метаданные, `local/adapter.py`, тесты.
**Дата:** 2026-11-16.
**Связано:** [ADR-0005](0005-audio-engine.md), [ADR-0007](0007-usb-mixtape.md), [RISKS](../RISKS.md),
[бета-чеклист](../BETA-CHECKLIST.md).

## Контекст

Репозиторий публичный, но файла `LICENSE` нет, а метаданные пакета объявляют
`Proprietary`. Для бета-раздачи это хуже любого выбора: пользователь не знает
прав, а сборка формально запрещает распространение.

Что реально попадает в поставку и какие у этого лицензии:

| Компонент | Лицензия | Как связан |
|---|---|---|
| Код NeuroWave | **не выбрана** | — |
| `mpv` | GPL-2.0-or-later | отдельный процесс, общение по JSON IPC |
| `libmpv` (если встроить) | GPL-2.0-or-later (при обычной сборке) | линковка меняет обязательства |
| `mutagen` | GPL-2.0-or-later | импорт в Python-процесс, extras `[local]` |
| `tinytag` | MIT | кандидат на замену `mutagen` |
| PySide6 | LGPL-3.0 | динамическая линковка, Qt Widgets |
| `dbus-next`, `keyring` | MIT | импорт |
| `requests` | Apache-2.0 | импорт |
| FFmpeg-библиотеки внутри mpv | зависит от сборки mpv | для нас — чужой процесс |

Ключевой вопрос — `mutagen`. Он используется **только для чтения тегов**
локальных файлов (`local/adapter.py`, `mutagen.File(path, easy=True)`), записи
тегов в проекте нет.

## Измерение: закрывает ли `tinytag` наши потребности

Сравнение на реальных файлах, сгенерированных ffmpeg (MP3 320k, OGG/Vorbis,
M4A/AAC) и на FLAC из тестового набора:

| Формат | Поля | mutagen | tinytag |
|---|---|---|---|
| MP3 | title/artist/album | совпали | совпали |
| MP3 | длительность | 2.04 с | 2.04 с |
| MP3 | bitrate | 320000 (бит/с) | 320.0 (кбит/с) |
| OGG | title/artist/album/duration | совпали | совпали |
| M4A | title/artist/album | совпали | совпали |
| FLAC | title/artist/album/duration | совпали | совпали |

Отличие одно и важное: **tinytag отдаёт bitrate в кбит/с**, mutagen — в бит/с;
при замене нужен перевод единиц. Запись тегов не поддерживается ни одним из
наших сценариев, поэтому ограничение tinytag (read-only) не мешает.

Побочная находка: `sandbox/music/tone.mp3` — валидный MP3 по `file`, но
`mutagen` падает на нём с `HeaderNotFoundError`, а `tinytag` и mpv файл
читают. Это довод в пользу замены, но не доказательство: файл нетипичный.

## Варианты

### A. GPL-3.0-or-later

* Плюсы: совместимо с `mutagen` и `mpv`, не требует менять код, привычно для
  музыкальных плееров.
* Минусы: любой, кто встроит код в закрытый продукт, обязан открыть исходники;
  часть библиотек (например, Apache-2.0) придётся проверять на совместимость
  при линковке.

### B. MIT + замена `mutagen` на `tinytag`

* Плюсы: максимальная свобода для пользователей и упаковщиков; `tinytag`
  покрывает измеренные поля, запись тегов не нужна.
* Минусы: нужен отдельный PR (`local/adapter.py`, `doctor`, extras, тесты);
  `[local]`-вариант с `mutagen` придётся либо убрать, либо явно помечать как
  GPL-режим; Apache-2.0 (`requests`) с MIT совместим, с GPLv2 — нет (это
  аргумент против GPL-2.0-only, но не против GPL-3.0).

### C. Proprietary (текущее значение в `pyproject.toml`)

* Несовместимо с публичным репозиторием и бета-раздачей. Должно быть изменено
  в любом случае.

## Рекомендация

**Вариант B (MIT + `tinytag`)**, потому что:
1. `mutagen` нужен только для чтения тегов, и `tinytag` покрывает все
   измеренные поля на MP3/OGG/M4A/FLAC;
2. это снимает GPL с Python-процесса, оставляя GPL только у отдельного mpv;
3. `tinytag` — одна зависимость вместо GPL-модуля в основном дереве импортов.

Если владелец выбирает GPL-3.0 (вариант A), ничего менять не нужно, кроме
добавления `LICENSE` и правки `pyproject.toml`.

## Решение владельца (2026-11-16)

**Вариант B: MIT + `tinytag`.** Что сделано:

1. `LICENSE` — MIT, правообладатель `NeuroWave contributors` (если нужен
   другой правообладатель, меняется одна строка в `LICENSE`).
2. `pyproject.toml`: `license = "MIT"`, `license-files = ["LICENSE"]`,
   классификатор MIT, `local = ["tinytag>=1.10"]`.
3. `local/adapter.py` читает теги через `tinytag`; `mutagen` не импортируется
   нигде в `src/` (проверяется тестом), `doctor` показывает `tinytag`.
4. Тесты: чтение тегов из WAV с RIFF INFO (без ffmpeg), «;» как разделитель
   исполнителей, единицы bitrate (кбит/с), отсутствие `tinytag` → имена файлов,
   битый файл остаётся доступным, отсутствие `mutagen` в проекте и MIT в
   `LICENSE`.
5. `mutagen` удалён из venv и из зависимостей; `pip install -e '.[local]'`
   ставит только MIT-пакет.

Проверка поставки: в wheel и sdist попадает `LICENSE`; установка из wheel в
чистом venv не тянет GPL-пакеты.

`ADR-0007` занят USB Mixtape; нумерация решений не пересекается.
