Статус на 2026-11-16. «Готово» означает: проверено на целевой машине
(Linux Mint 22.3, Ryzen 7 5800X, PipeWire 1.0.5, Bose QC Ultra по SBC), есть

## Не проверено (известные пробелы)

| Что | Что известно |
|---|---|
| Физический звук HDMI | HDMI-порт машины не подключён. Звук проверен на дисплее Acer VG270 S, подключённом по DP-2: EDID заявляет LPCM 2ch, сигнал доходит до цифрового выхода NVIDIA (пик −45.4 dBFS при volume 35 %), sink активен. На слух не подтверждён: у машины нет человека, который слышал бы колонки монитора |
| Bluetooth-кодеки кроме SBC | Устройство (Bose QC Ultra) предлагает только SBC, SBC-XQ и mSBC. В PipeWire есть плагин LDAC (`libspa-codec-bluez5-ldac.so`, libldac установлен), но Bose LDAC не поддерживает; плагина AAC в сборке нет. Проверить AAC/LDAC не на чем — это ограничение устройства и сборки, а не отказ кодека |
| 96/192 кГц и многоканальный материал | замеры на 44.1/48 кГц |
| Долгий soak | Пройден: 6 часов, 2690 смен трека, утечек не видно (см. «Soak»). Нюанс: тот прогон шёл под давлением памяти машины, поэтому PSS/RSS просели из-за свопа; суммарный след RSS+swap тогда не писался. Скрипт теперь пишет swap и RSS+swap — контрольный прогон с новыми колонками прошёл |
| Спектроанализатор | gate PCM-tap пройден, FFT не реализован и не входит в MVP |
| Пакеты `.deb`/Flatpak, подпись | нет; есть wheel/sdist и `install-desktop.sh` |
| Восстановление после смены сети | не проверялось отдельно |
| Accessibility (клавиатура, экранный чтец) | не проверялось |

## Soak

Скрипт: `packaging/soak.py`, mpv `--ao=null`, тон-треки по 8 с, repeat=all,
сэмплы PSS/CPU/дескрипторов раз в минуту. С 2026-11-17 дополнительно
измеряется `VmSwap` обоих процессов и суммарный след RSS+swap: PSS не видит
выгруженные страницы, поэтому при свопе одна только память по PSS врёт.

Прогон 16 минут, 120 автопереходов, mpv `--ao=null`, профиль по умолчанию:

| Метрика | Старт | Конец | Дрейф |
|---|---|---|---|
| Python PSS | 50.0 МБ | 49.0 МБ | −1.0 МБ |
| mpv PSS | 59.3 МБ | 68.0 МБ | +8.7 МБ (прогрев буферов, RSS стабилен 67.9) |
| Дескрипторы | 113 | 113 | 0 |
| Потоки | 3 | 3 | 0 |
| CPU Python | — | 0.8 с за 958 с | 0.08 % ядра |

Вердикт скрипта: утечек не видно. Это **не** замена 6-часовому прогону: цель
по плану — 6 часов, сделано 16 минут.

### Прогон на 6 часов (2026-11-16 → 2026-11-17)

Тот же скрипт, `--minutes 360`, mpv `--ao=null`, тон-треки по 8 с, repeat=all,
сэмпл раз в 30 с (71 строка CSV).

| Метрика | Старт | Максимум | Конец |
|---|---|---|---|
| Python PSS | 48.7 МБ | 48.7 МБ | 5.1 МБ |
| mpv PSS | 67.4 МБ | 68.4 МБ | 18.2 МБ |
| Python RSS | 58.9 МБ | 59.0 МБ | 11.4 МБ |
| Дескрипторы | 113 | 113 | 113 |
| Потоки | 3 | 3 | 3 |
| CPU Python | — | — | 17.2 с за 21 596 с (0.08 % ядра) |

Длительность 359.9 мин, 2690 смен трека, вердикт скрипта: **утечек не видно** —
дескрипторы и потоки стабильны, CPU фоновый, PSS/RSS не растут.

Оговорка про интерпретацию: машина в это время испытывала нехватку памяти
(свободная RAM кончилась, активный был своп), поэтому PSS и RSS у обоих
процессов просели — PSS не видит выгруженные в своп страницы. «Просели» здесь
значит «ушли в swap», а не «утекли», но в том прогоне swap не измерялся, и
сравнить суммарный след было нечем.

Поэтому `packaging/soak.py` теперь дополнительно пишет `VmSwap` обоих
процессов и суммарный RSS+swap в CSV, а в итог — строки «Python RSS+swap»
и предупреждение, если что-то ушло в своп. Контрольный прогон на 3 минуты с
новыми колонками прошёл: swap 0.0 МБ, RSS+swap 58.7 → 58.8 МБ, fd 68 → 68,
потоки 3 → 3, вердикт — утечек не видно.

## Память с интерфейсом

Ориентир 200 МБ PSS. Замеры без GUI: 127.7 МБ (Bluetooth) и 121.8 МБ (HDMI),
см. [SPRINT0-MEASUREMENTS.md](SPRINT0-MEASUREMENTS.md).

| Сценарий | Python (PSS) | mpv (PSS) | Итого |
|---|---|---|---|
| Окно + ядро, mpv `--ao=null`, профиль `bluetooth` | 67.1 МБ | 56.6 МБ | 123.7 МБ |
| Окно + ядро, реальный Bluetooth, локальный WAV, громкость 5 % | 65.8 МБ | 52.4 МБ | 118.2 МБ |

Оговорка: размер mpv зависит от потока. На сетевом MP3 320 в Sprint 0 mpv
занимал 83.6 МБ; с окном это даёт оценку **≈150 МБ** — всё ещё ниже 200 МБ, но
прямого замера «GUI + сетевой MP3 320 по Bluetooth» не делали.
