# Бета-чеклист NeuroWave

Статус на 2026-11-16. «Готово» означает: проверено на целевой машине
(Linux Mint 22.3, Ryzen 7 5800X, PipeWire 1.0.5, Bose QC Ultra по SBC), есть
тест или записанный замер. Всё остальное — честно открыто.

## Готово и проверено

| Что | Чем подтверждено |
|---|---|
| Воспроизведение, очередь, «Моя волна», поиск, библиотека, плейлисты, лайки | живые прогоны на реальном аккаунте, [QA-прогон](QA-RUN-2026-11-16.md) |
| Автопереход, repeat/shuffle, кеш | 408 тестов, живые переходы с `(кеш)` |
| MPRIS, трей, Desktop entry | `gdbus`, `install-desktop.sh` |
| Qt-окно: транспорт, громкость, профиль, выход, Sound Lab | offscreen-тесты, ручной прогон |
| Безопасная громкость (>100 % не применяется) | [ADR-0005](decisions/0005-audio-engine.md), живые замеры усиления |
| DSP-модель, пресеты, свои профили | 40+10 unit, 5+1 интеграционных с живым mpv |
| Применение DSP с проверкой и откатом | 19 тестов рантайма, живой mpv |
| Менеджер выходов BT/HDMI с реальным кодеком | 28 тестов, живое переключение на HDMI и обратно |
| PCM-tap только своего потока | [gate](SPRINT0-MEASUREMENTS.md): изоляция −86…−92 дБ, +5 мс |
| CI: pytest 3.10–3.12, живой mpv, Qt offscreen | зелёные прогоны на GitHub Actions |
| Сборка wheel/sdist, установка из wheel | проверено в чистом venv: `--version`, `sound --profiles`, `doctor` |
| Нет секретов и личных данных в репозитории | проверка `git log -p` на токены/uid/логин |

| Что | Почему открыто |

## Не проверено (известные пробелы)

| Что | Что известно |
|---|---|
| Физический звук HDMI | sink и переключение работают, но колонки/ресивер не слушали |
| Bluetooth-кодеки кроме SBC | AAC/LDAC не включались; `api.bluez5.codec = sbc` |
| 96/192 кГц и многоканальный материал | замеры на 44.1/48 кГц |
| Долгий soak | см. раздел «Soak» ниже; цель 6 часов не достигнута |
| Спектроанализатор | gate PCM-tap пройден, FFT не реализован и не входит в MVP |
| Пакеты `.deb`/Flatpak, подпись | нет; есть wheel/sdist и `install-desktop.sh` |
| Восстановление после смены сети | не проверялось отдельно |
| Accessibility (клавиатура, экранный чтец) | не проверялось |

## Soak

Скрипт: `packaging/soak.py`, mpv `--ao=null`, тон-треки по 8 с, repeat=all,
сэмплы PSS/CPU/дескрипторов раз в минуту.

Прогон 16 минут, 120 автопереходов, mpv `--ao=null`, профиль по умолчанию:

| Метрика | Старт | Конец | Дрейф |
|---|---|---|---|
| Python PSS | 50.0 МБ | 49.0 МБ | −1.0 МБ |
| mpv PSS | 59.3 МБ | 68.0 МБ | +8.7 МБ (прогрев буферов, RSS стабилен 67.9) |
| Дескрипторы | 113 | 113 | 0 |
| Потоки | 3 | 3 | 0 |
| CPU Python | — | 0.8 с за 958 с | 0.08 % ядра |

Вердикт скрипта: утечек не видно. Это **не** замена 6-часовому прогону: цель
по плану — 6 часов, сделано 16 минут. Долгий прогон остаётся открытым.

## Память с интерфейсом

Ориентир 200 МБ PSS. Замеры без GUI: 127.7 МБ (Bluetooth) и 121.8 МБ (HDMI),
см. [SPRINT0-MEASUREMENTS.md](SPRINT0-MEASUREMENTS.md).

| Сценарий | Python (PSS) | mpv (PSS) | Итого |
|---|---|---|---|
| Окно + ядро, mpv `--ao=null`, профиль `bluetooth` | 67.1 МБ | 56.6 МБ | 123.7 МБ |
| Окно + ядро, реальный Bluetooth, локальный WAV, громкость 5 % | 65.8 МБ | 52.4 МБ | 118.2 МБ |

Оговорка: размер mpv зависит от потока. На сетевом MP3 320 в Sprint 0 mpv
занимал 83.6 МБ; с окном это даёт оценку **≈150 МБ** — всё ещё ниже 200 МБ, но
прямого замера «GUI + сетевой MP3 320 по Bluetooth» не делали.
