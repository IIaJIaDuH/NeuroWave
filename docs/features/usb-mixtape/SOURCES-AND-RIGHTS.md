# USB Mixtape — источники, права, лицензии и политика загрузок

**Статус:** политика реализована для локального источника (USB-02); сетевых загрузок нет.  
**Цель:** гарантировать, что Mixtape копирует **только аудио, реально допускаемое к автономному использованию**, и не путает доступ к потоку, наличие кеша, право на файл и права на его повторное распространение.

## 1. Четыре разных состояния

1. **Discoverable:** трек присутствует в каталоге или рекомендациях.
2. **Playable:** провайдер даёт stream_url/remote-playback для обычного прослушивания.
3. **Offline-in-app:** официальное приложение может хранить данные для собственного офлайн-режима.
4. **Exportable:** пользователь имеет законно доступную копию аудиофайла и право его использовать для целевого экспорта с учётом условий источника.

Ни один из пунктов 1–3 **не** влечёт пункт 4. Параметр существующего ProviderInfo.cache_allowed описывает кеш плеера, **НЕ** экспорт. Capability.DIRECT_STREAM описывает воспроизведение, **НЕ** загрузку копии.

| Источник | Для рекомендаций | Для файла USB | Когда разрешено |
|---|---|---|---|

| Купленные DRM-free загрузки | Да | **Да** | Файл реально принадлежит пользователю, права/условия позволяют такую копию |

## 3. Политика разрешения

**Первая версия (MVP):**

- Пользователь выбирает локальную библиотеку. По умолчанию только файлы в разрешённом root (например, ~/Music).
- Источник создаёт ExportAsset после проверки обычного файла, фактического формата, размера, доступа на чтение и статуса права; для локальных файлов источник права — согласие пользователя на использование его файлов в личной подборке.
- В спорных юридических ситуациях система не выдаёт окончательного правового заключения; пользователь подтверждает наличие прав на копирование, а приложение не обходит технические ограничения.
- Файл из кеша NeuroWave, если он появился вследствие потокового воспроизведения, **не является** допустимым источником LocalExportSource, даже если лежит в области доступных пользователю файлов. SourceRoot должен исключать XDG cache и служебные каталоги.
- Метаданные провайдеров используются для ранжирования и подсказок, но по умолчанию не вызывают сетевые загрузки.

**Сетевые загрузки (только будущий PR после gate):**

1. Upstream имеет документированное право на **original-file download**, а не только разрешение stream.
2. API разрешает стороннему клиенту скачивать именно оригинал; не нужно авторизоваться через чужие cookie, обходить механизмы защиты или догадываться по скрытому URL.
3. Пользователь дал consent для конкретного источника и условий скачивания.
4. Адаптер умеет verify rights для каждого asset. UNKNOWN / unavailable / revoked → skip; запись не продолжается «на удачу».
5. Для licence-required attribution сохранять лицензионное уведомление/автора согласно условиям и не скрывать происхождение.
6. Ограничить размер/время/число загрузок, уважать rate limits, не логировать токены/персональные URL, обрывать после отзыва разрешения.
7. HTTP скачивание реализуется отдельным bounded streaming клиентом с ограничением редиректов, TLS, allowlist upstream и запретом private network/localhost/metadata IP (SSRF defence).
8. Нельзя трактовать URL с редиректом как лицензированную загрузку автоматически: право связано с asset и источником, а не HTTP 200.
9. Повторный аудит ToS/API и версии перед публикацией бинарной сборки.

## 4. SoundCloud — важная граница

Официальная справка SoundCloud сообщает, что скачивание отдельного трека доступно, когда автор включил download и слушатель вошёл в учётную запись; загружается файл исходного формата, а не любой поток. Это **не** подтверждает, что уже используемый NeuroWave SoundCloud API позволяет автоматически получить такой файл. До исследования официального способа скачивания и применимых условий автоматический SoundCloudDownloader **не реализовывать**.

Ресурсы:
- https://help.soundcloud.com/hc/en-us/articles/115003448787-Downloading-tracks
- https://help.soundcloud.com/hc/en-us/articles/31423603670043-Manage-your-track-s-permissions-and-advanced-settings

## 5. Матрица решений по качеству

| Исходник | Запрошен Original | Запрошен MP3 | Запрошен FLAC |
|---|---|---|---|
| MP3 | Copy | Copy, если совместим; иначе предупредить об ухудшении при перекодировке | Skip для FLAC-only, НЕ upscale |
| FLAC (настоящий lossless) | Copy | Конвертировать при согласии, указать lossy conversion | Copy |
| Opus/AAC/Ogg | Copy при совместимости устройства | Конвертировать с предупреждением о повторном lossy encoding | Skip для FLAC-only |
| WAV/AIFF | Copy | Конвертировать | Конвертировать в lossless FLAC |
| Неизвестен codec или повреждён заголовок | Skip + причина | Skip | Skip |

Надпись MP3 320 kbps описывает **скорость конечного кодирования**, а не гарантирует высокое качество входа. Оригиналы не перекодировать без нужды. Целевой формат Car USB может быть ограничен возможностями автомагнитолы (bitrate, VBR/CBR, ID3 версия, charset, папки).

## 6. Юридические и лицензионные обязанности ПО

- Аудиофайл и **исходный код приложения** лицензируются отдельно. Права на запись музыки не следуют из MIT/GPL NeuroWave.
- Сейчас pyproject.toml у NeuroWave объявляет Proprietary, выбор собственной лицензии публичного релиза ещё требуется.
- ffmpeg/libmp3lame и весь bundled runtime требуют проверки фактических лицензий и опций сборки. Вызов внешнего ffmpeg не отменяет обязательств при распространении бинарника.
- mutagen — GPL-2.0-or-later (существующий optional extra local). Изучить переход на TinyTag MIT для чтения, но не предполагать его поддержки записи тегов или обложек без проверки.
- Для CC-материала: сохранять обязательную атрибуцию, лицензию, ссылку при применимости и изменения; не выдавать лицензию трека за личную рекомендацию.
- Никаких обходов ToS под названием «режим исследователя», «user-agent», «внешний скрипт» и т. п.

## 7. Экспортные метаданные

Для каждого фактического файла:

~~~json
{
  "source_id": "local",
  "asset_id": "library-asset-123",
  "rights_basis": "USER_OWNED",
  "origin": "user_local_library",
  "dest_relative": "MUSIC/NeuroWave/001 - Artist - Title.mp3",
  "source_format": "flac",
  "output_format": "mp3",
  "converted": true
}
~~~

Пример иллюстративный; не включает приватные абсолютные пути, токены и URL. Реальная схема, версия и полномочия утверждаются при реализации.

## 8. Проверки PR с новым провайдером

- [ ] Доказано API/документацией и тестом, что доступна именно **загрузка файла**, а не поток.
- [ ] Есть явная проверка права на каждом asset; неизвестный статус ведёт к отказу.
- [ ] Авторизация и TLS не обходятся, нет захвата сетевого аудио или экспортирования MPV cache.
- [ ] Метаданные лицензий/атрибуции сохраняются корректно.
- [ ] При отсутствии API/токена/прав пользователь получает ясное сообщение; локальный экспорт продолжает работать.
- [ ] Юридический чек перед бинарной поставкой выполнен.
