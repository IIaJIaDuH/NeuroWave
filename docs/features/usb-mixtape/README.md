# NeuroWave USB Mixtape

**Статус: USB-01…USB-06 (планировщик, источник, устройства, writer, транскод/M3U8/Car, headless CLI) реализованы; Qt-экран и аппаратная проверка — план**
**Дата:** 2026-11-17
**Цель:** автоматически подготовить персональный сборник музыки из **файлов, разрешённых к экспорту**, и безопасно записать его на выбранный USB-носитель.

## Суть

Пользователь подключает USB-накопитель, выбирает музыкальный сценарий (в дорогу, вечеринка, релакс, избранное), желаемую длительность и формат. NeuroWave собирает кандидатный список с учётом предпочтений, **находит реально доступные к экспорту аудиофайлы**, показывает предварительный план, после явного подтверждения записывает и проверяет результат. При необходимости предлагает безопасное извлечение.

**Ключевое разграничение:** рекомендация трека, наличие стриминговой ссылки, кеш для прослушивания и право **получить автономный музыкальный файл** — четыре разных понятия. Нет права на экспорт → нет записи. Кнопка «скачать всё» не означает обход DRM или условий сервиса.

## Пользовательский маршрут

1. Подключить USB → увидеть подтверждённый съёмный том, его объём, файловую систему, свободное место.
2. Выбрать профиль: **Car USB / Party / Chill / Favorites**. Задать длительность 1–12 часов, размер, формат **Original / MP3 (до 320 kbps) / FLAC only if source is lossless**.
3. Получить результат планировщика: **доступно / нужно разрешённо получить / недоступно**, сколько часов, какие файлы и сколько места потребуется.
4. Просмотреть список. Убрать неуместные песни, выбрать порядок, отметить «без повторов», подтвердить конкретный том и список записываемых файлов.
5. Следить за ходом копирования/конвертации, видеть ошибки и оставшееся место.
6. Проверить контрольные суммы и итоговый M3U/M3U8; получить результат и безопасно извлечь накопитель.

## Область первой реализации (MVP)

- Только **Linux Mint / Linux**, путь к USB через UDisks2 (D-Bus); без root, форматирования, создания разделов или произвольной записи в системные каталоги.
- Файлы из **локальной библиотеки пользователя**, принадлежащие пользователю или разрешённые для личного экспорта. Не экспортировать потоковые кеши, даже когда они хранятся как MP3.
- Планирование подборки **локальным детерминированным алгоритмом**, без обязательного LLM.
- Безопасное копирование с продолжением через журнал задачи, проверкой записанного, обработкой выдёргивания носителя.
- Функциональный CLI / headless API раньше GUI; кнопка в Qt — поздний этап.

## За рамками MVP

- Принудительное скачивание Яндекс Музыки, Spotify, YouTube и иных потоков, обход DRM или подписки.
- Форматирование USB, запись образов дисков, изменение чужих данных без явного согласия.
- Автоматическая запись без подтверждения, скрытое удаление старых песен.
- Генеративный ИИ-диджей, синтез новых треков, облачная синхронизация личного профиля.
- Гарантия совместимости с любой магнитолой: профиль устройства сначала проверяется на реальном железе.

## Принципы проекта

Звук и надёжность важнее эффектов; никаких юридических серых зон; RAM/CPU измеряем, но не жертвуем работоспособностью ради цифр. Весь модуль должен быть **отключаемым** и не вмешиваться в mpv IPC, PlayerService или аудиотракт (ADR-0005).

**Шутливый тест продукта:** система никогда не подменяет просьбу пользователя на чужой вкус. Даже если ИИ решил, что вместо Rammstein всем нужен персональный марафон Ольги Бузовой.
