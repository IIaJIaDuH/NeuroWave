# Roadmap NeuroWave

Статусы: `[ ]` — запланировано, `[x]` — реализовано в коде (проверка на реальном аккаунте и устройствах отмечается отдельно).

## Sprint 0 — Technical Discovery
- [ ] Проверить действующую авторизацию в рамках API и подписки.
- [ ] Собрать и запустить CloudMus и YaMusic на Linux Mint.
- [ ] Измерить память, CPU, старт и воспроизведение на Bluetooth/HDMI.
- [ ] Проверить способы доступа к PCM и встраивания DSP.
- [ ] Провести аудит лицензий и зависимостей.
- [ ] Выбрать архитектуру отдельным ADR.

**Gate:** воспроизводится доступный трек, работает библиотека/волна, понятны ограничения и лицензии.

## Sprint 1 — Core MVP
- [x] Авторизация (Device Flow), безопасное хранение сессии в keyring.
- [x] Очередь, библиотека, поиск, лайки, «Моя волна». Реализовано в headless-ядре.
- [x] Вывод через mpv, обработка сбоев сети и недоступных треков.
- [x] Кеш с квотой, LRU/TTL; история и снимок очереди в SQLite; CLI и диагностика.
- [ ] Явный выбор аудиоустройства Bluetooth/HDMI из приложения (сейчас — системный маршрут).
- [ ] Системный трей и MPRIS.
- [ ] Smoke-тест на Linux Mint с реальным аккаунтом и устройствами.

Детали реализации и ограничения: [IMPLEMENTATION.md](IMPLEMENTATION.md).

## Sprint 2 — Sound
- [ ] Pure Hi-Fi bypass и Enhanced DSP.
- [ ] EQ, preamp и anti-clipping limiter.
- [ ] Пресеты Bluetooth/HDMI.
- [ ] Измерения A/B с браузером.

## Sprint 3 — User experience
- [ ] Футуристичный UI, темы, мини-плеер.
- [ ] Спектроанализатор по PCM с автоотключением при сворачивании.
- [ ] Тексты, плейлисты, подкасты и синхронизация по мере реальной поддержки API.

## Sprint 4 — AI DJ
- [ ] Локальный профиль вкуса и правила рекомендаций.
- [ ] Подключаемая LLM, строгие tool schemas.
- [ ] Запросы на естественном языке; push-to-talk.
- [ ] Privacy controls, измерения затрат памяти.

## Sprint 5 — Experimental studio
- [ ] Изолированный генератор оригинальной музыки.
- [ ] Исследовать совместимость ACE-Step с целевой GPU.
- [ ] Очередь генераций и сохранение пользовательских работ.

## Release gate
Тесты на реальном аккаунте, отчёт о RAM/CPU, проверка лицензий, отсутствие секретов в репозитории, инструкция установки и чёткие ограничения сервиса.
