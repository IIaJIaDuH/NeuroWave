## Sprint 0 — Technical Discovery
- [x] Проверить действующую авторизацию в рамках API и подписки.
- [x] Собрать и запустить CloudMus и YaMusic на Linux Mint — [короткий тест](COMPARISON-CLOUDMUS-YAMUSIC.md): старт, PSS, CPU, локальное воспроизведение. Вход в Яндекс у обоих не выполнялся (интерактивный браузер; токен живого аккаунта в сторонние бинарники не переносили).
- [x] Измерить память, CPU, старт и воспроизведение на Bluetooth/HDMI.
- [x] Проверить способы доступа к PCM и встраивания DSP.
- [x] Провести аудит лицензий и зависимостей.
- [x] Выбрать архитектуру отдельным ADR — [ADR-0005](decisions/0005-audio-engine.md).

Цифры и методика — в [замерах Sprint 0](SPRINT0-MEASUREMENTS.md). Сравнение CloudMus/YaMusic **выполнено в ограниченном объёме** (запуск, память, CPU, локальный FLAC); полноценная авторизация и сравнение стриминга конкурентов с живым аккаунтом не выполнялись — см. [отчёт](COMPARISON-CLOUDMUS-YAMUSIC.md).

**Gate:** воспроизводится доступный трек, работает библиотека/волна, понятны ограничения и лицензии.

## Провайдеры музыки
- [x] Контракт возможностей (`Capability`), реестр и entry points для сторонних провайдеров.
- [x] Отдельный токен на провайдера, команда `providers`, выбор `--provider`.
- [x] Квалифицированные ID `provider:track_id` в треках, истории, кеше и снимке очереди, миграция SQLite v1→v2 и маршрутизация `stream_url`/feedback по провайдеру — гейт из [ADR-0004](decisions/0004-multi-provider.md) закрыт.
- [x] Локальные файлы (`--provider local`, папка `local_music_dir`): без аккаунта, DRM и кеша.
- [ ] MPD как внешняя библиотека (локальный провайдер уже читает файлы с диска).
- [x] SoundCloud (`--provider soundcloud`): поиск и поток `playable`-треков, ключ через `login --token`, атрибуция автора, кеш отключён; превью и `blocked` в очередь не попадают.
- [x] Spotify только как «пульт»: каталог, `devices`/`connect`/`remote`, `DELEGATED_PLAYBACK` без потока и кеша.
- [ ] VK, Deezer, TIDAL, Apple Music, YouTube Music — только при появлении официальной потоковой поддержки.

## Технический долг

Подробности и обоснования — в [отчёте](REPORT-2026-11-16.md#технический-долг-и-хвосты).

- [ ] Spotify: OAuth PKCE с браузером вместо ручного `--token/--refresh-token/--client-id`.
- [ ] Spotify: проверять refresh token при входе и подсказывать недостающие scopes при `403`.
- [ ] Spotify: `remote --device`, чтобы не делать `connect` отдельной командой.
- [ ] SoundCloud: обновление ключа без повторного входа; кеш метаданных доступа в памяти.
- [ ] `doctor`: не требовать `mpv` у провайдеров без `DIRECT_STREAM`.
- [ ] `me`: не ходить в сеть каждый раз (последнее известное состояние).
- [ ] Кеш: предупреждение, если свободного места меньше квоты.
- [ ] MPRIS/трей: проверка на живой панели Cinnamon; интеграционный тест с настоящим `mpv`.
- [x] CI и лицензия MIT (ADR-0006), регрессионный тест на отсутствие GPL-Mutagen.
- [ ] Релизный тег, проверка установки стороннего пакета через entry points и аудит конкретного бинарного комплекта.

| 10 | Beta hardening: тесты, упаковка, soak, чеклист (лицензия — за владельцем) | [x] |

Правила, которые не обсуждаются на ходу:

* «Больше 100 % без клиппинга» сначала доказывается измерениями (включая
  inter-sample peaks и oversampling), и только потом включается.
* GPL не добавляется без причины: `mutagen` заменён на MIT-`tinytag`
  ([ADR-0006](decisions/0006-license.md)), проект под MIT.
* Память меряем вместе с интерфейсом: ориентир 200 МБ PSS — цель, а не
  религия; стабильный звук важнее цифры.
* Лицензия **MIT выбрана** ([ADR-0006](decisions/0006-license.md)); публичная **бинарная** раздача по-прежнему требует аудита фактических сторонних бинарников/NOTICE и [бета-чеклиста](BETA-CHECKLIST.md).
