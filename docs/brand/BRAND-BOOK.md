# Neyrowave / DJ Franky — мини-брендбук v0.1

**Status:** design direction, not production assets. Пересмотр палитры и начертаний после первых реальных иконок и контрастных тестов.

## 1. Голос бренда

- **Личность:** технически грамотный, дружелюбно дерзкий, влюблённый в качество звука; шутит, не врёт и не мешает музыке.
- **Общение:** простые русские формулировки, умеренная ирония. В пользовательском интерфейсе — ясность важнее мема. В соцсетях возможно чуть более язвительно.
- **Запрещённые обещания:** «идеальный Hi-Fi», «bit-perfect» без замеров, «все источники доступны для скачивания», «ИИ угадывает вкус со 100% точностью».
- **Человек управляет музыкой:** персонализация — предложение, не приказ.

## 2. Слоганы — рабочие варианты

**Основной кандидат:** «Собран из кода. Оживлён музыкой.»

Вторичные (для кампаний, не включать все в UI):
- «Звук — без компромиссов. Код — без хаоса.»
- «Твоя волна. Твой бит. Твой Franky.»
- «Франкенштейн с хорошим музыкальным вкусом. Но последнее слово — твоё.»
- «Sound first. Monster second.»
- «DJ Franky is in the mix.»

В UI соблюдать WCAG-контраст: текст не менее 4.5:1 (AA normal), крупный — 3:1, управление не сводить только к цвету. HEX — **предварительные дизайн-токены**; не менять существующую Qt-тему без отдельного PR и визуального теста.

## 4. Знак, логотип и читаемость

**Primary logo:** слово `Neyrowave` + головной символ Franky, горизонтальный вариант.  
**Secondary:** только голова в больших очках/наушниках, квадратная иконка.  
**Monochrome:** силуэт с 2–3 характерными элементами для 16–24 px и tray.

Нельзя:
- мелкие подписи, сложный портрет и тонкие линии внутри системной иконки;
- текст поверх глаз/лица или клипартные музыкальные ноты вокруг всего изображения;
- мутные неоновые свечения, которые съедают силуэт;
- копировать фирменные детали конкретных франкенштейновских кинообразов;
- передавать критические ошибки одним миганием/цветом.

**Типографика:** открытая читаемая современная grotesk-семья для кириллицы/латиницы, жирный заголовок и нейтральный интерфейсный текст. Использовать системный доступный шрифт по умолчанию; не встраивать сторонние шрифты без лицензии/доказанной необходимости.

## 5. Маркер узнаваемости Franky

- Асимметричная аккуратная линия шва у виска или лба.
- Чуть угловатая, но дружелюбная большая голова, понятная в малом размере.
- Очки с цельным отражением в форме звукового импульса или двух световых полос (по желанию).
- Большие круглые чашки наушников и мягкое оголовье.
- Лёгкая ухмылка «я знаю, какой сейчас будет дроп».
- Характерный мятно-зелёный тон кожи **без кислотного свечения по всей площади**.

## 6. Использование в интерфейсе

- Первое открытие: статичный символ (не блокировать старт потоков).
- Now Playing: анимация только по opt-in и только при наличии проверенного PCM/энергии.
- Нет звука/пауза: плавный переход в idle; не создавать псевдосинхронизацию.
- Loading/error: понятный статус и обычная анимация состояния без громкой реакции или навязчивости.
- Reduced motion и low-power: статичный символ по умолчанию.

## 8. Критерии визуальной приёмки

- [ ] Узнаётся на 16, 24, 32, 64 и 256 px на тёмном и светлом фоне.
- [ ] И без цвета видны «очки + наушники + шов + характер».
- [ ] Не выглядит как баннер букмекерской конторы или generic neon-AI.
- [ ] Отсутствует обязательная анимация для выполнения основной функции.
